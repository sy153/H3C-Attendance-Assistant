# H3C 考勤工时助手

一个运行在 H3C EIP 考勤页面上的 Tampermonkey 用户脚本，把日历上零散的打卡记录换算成**本月工时差**，并在日历上直接标出每一天是盈余、缺少、异常还是周末加班。

> 当前版本：**4.4.7**（单文件用户脚本，无构建、无依赖、无网络请求）

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 工时差计算 | 每个工作日的「实际净工时 − 标准净工时」累加成当月工时差 |
| 周末加班 | 单独统计，不计入工作日工时差 |
| 特殊考勤识别 | 年休假、调休假、病假、事假、婚假、产假、陪产假、丧假、出差、外出、培训、居家办公 |
| 半天假支持 | 识别 `（09:00-12:00）` 形式的请假区间，按扣除后的应工作时长计算 |
| 日历着色 | 绿=盈余、红=不足、琥珀=数据异常、蓝=周末加班、紫=特殊考勤、灰=持平 |
| 每日明细 | 逐日展开实际打卡、应下班时间、净工时、午休扣除、异常原因 |
| 补时建议 | 按剩余工作日把当前缺口摊到每天 |
| 历史趋势 | 本地保存最近 6 / 12 个月的工时差，画成柱状图（最多保留 36 个月） |
| 页面统计 | 抓取页面上的「忘刷卡次数」与「预配年假余额」 |
| 三种面板形态 | 完整 / 紧凑 / 迷你，可拖动、位置和设置都会记住 |
| 8 套主题 | 跟随系统、白底极简、深色科技、OLED 纯黑、海洋蓝、森林绿、暖阳米黄、樱花粉 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或其他支持 `GM_*` API 的脚本管理器）。
2. 打开管理器的「添加新脚本」。
3. 把本仓库中的 `H3C 考勤工时助手-4.4.2.txt` **全文**粘贴进去，保存。
4. 打开 `https://eip-cw.h3c.com/myCenter/kaoqin`（或 `https://eip.h3c.com/myCenter/kaoqin`），面板会自动出现在页面右侧。

> 文件后缀是 `.txt` 而不是 `.user.js`，所以直接打开 Raw 链接**不会**自动唤起安装，需要手动粘贴。若想自动安装，下载后重命名为 `H3C 考勤工时助手.user.js` 再拖进浏览器即可。

**更新**：脚本头带 `@version`，把新内容覆盖到已有脚本即可；油猴会识别版本变化。设置、面板位置和趋势数据都存在本地，覆盖脚本不会丢。

## 使用

### 面板

首次进入考勤页后，脚本在页面**右上角**（距顶 90px、距右 20px）挂一个浮动面板：

- **拖动**：按住面板标题（或迷你态的整块）拖动，位置自动保存并限制在视口内。
- **完整模式**：工时差、工作日/周末统计、剩余工作日、忘刷卡、年假余额、补时建议、日历图例、计算规则、趋势图、每日明细。
- **紧凑模式**：只保留工时差、天数、周末加班。
- **迷你模式**：只显示一个数字，单击（或聚焦后按 <kbd>Enter</kbd> / <kbd>空格</kbd>）回到紧凑模式。
- **刷新**：重新读取当前页面并重算。
- **着色开关**：一键隐藏/显示日历着色，状态会记住。

### 日历着色

脚本不修改宿主页面的 class，只在格子元素上写 `data-h3c-status`，由注入的 CSS 渲染边框与底色。

| 颜色 | 含义 |
| --- | --- |
| 绿 | 工作日工时盈余 |
| 红 | 工作日工时不足 |
| 琥珀 | 打卡数据异常（缺一次卡、全天无打卡、跨度过大、超出弹性时间等） |
| 蓝 | 周末加班 |
| 紫 | 假期或特殊考勤（工时豁免） |
| 灰 | 工时持平 |

「打卡数据异常」和「未计入」的日子**不参与**工时差累加。

### 设置

点齿轮打开，可改：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 正常上班 | `08:30` | 标准班次开始 |
| 正常下班 | `18:00` | 标准班次结束 |
| 弹性最晚 | `09:30` | 晚于此时间打卡判为异常 |
| 午休开始 / 结束 | `12:00` / `13:30` | 与打卡区间重叠的部分会被扣除 |
| 日历着色 | 开启 | 关闭后不写任何格子属性 |
| 主题 | 白底极简 | 8 套可选 |
| 趋势月数 | 6 | 6 或 12 |
| 完整/紧凑宽度、透明度 | 450 / 325 / 98% | 有上下限校验 |

设置页还提供「清除本地趋势数据」。按 <kbd>Esc</kbd> 关闭设置面板。

## 计算规则

默认班次 `08:30–18:00`、午休 `12:00–13:30`：

```
标准净工时 = 下班时间 − 上班时间 − 与午休重叠的分钟数
           = 570 − 90
           = 480 分钟（8 小时）

工作日工时差 = Σ (实际净工时 − 标准净工时)
周末加班     = Σ (周末实际净工时)          ← 单独统计，不进上面的差
```

- **实际净工时** = 打卡跨度 − 与午休重叠的分钟数。
- **跨午夜**：打卡文本含「次日」或下班早于上班时，自动 `+24h`。
- **异常判定**（该日「未计入」）：
  - 只有上班或只有下班打卡；
  - 上下班都没有打卡（仅当前月已过去的工作日会补这条）；
  - 上班晚于「弹性最晚」；
  - 下班早于「正常下班」；
  - 单日打卡跨度超过 18 小时。
- **特殊考勤**（请假/出差/培训等）：工时豁免，不计入差额。带请假区间的半天假按「标准净工时 − 请假净时长」作为当天应工作。
- **剩余工作日**：当前月从**明天**起算；未来月份按整月算；历史月份不计算。
- **补时建议**：当前月且有剩余工作日时，把缺口平均摊到每个剩余工作日。

## 数据与隐私

- 脚本**不发送任何网络请求**，不上传任何数据。
- 所有状态存在油猴本地存储（`GM_setValue`），仅存于本机浏览器：

  | Key | 内容 |
  | --- | --- |
  | `h3c-attendance-helper-settings-v10` | 设置 |
  | `h3c-attendance-helper-history-v10` | 每月趋势数据（最多 36 条） |
  | `h3c-attendance-helper-position-v10` | 面板位置 |
  | `h3c-attendance-helper-display-mode-v10` | 当前面板形态 |

- 清除方式：设置页「清除本地趋势数据」，或在脚本管理器里删除该脚本的数据。

## 已知限制

- **无自动化测试**。改动目前只能靠代码审阅 + 真实页面验证。
- **强依赖宿主页面结构**：格子日期来自 `title` 属性（`YYYY-MM-DD｜…`）、打卡时间来自特定 Tailwind class、统计卡片来自 `.place-self-center-item-iconitem`。页面改版会**静默失效**（表现为「暂未找到考勤日历」或统计卡片显示 `--`），而不是报错。
- 请假区间必须写成 `（09:00-12:00）` 这类形式才会被识别。
- 界面上若出现「未打卡」等占位文案，可能被解析成打卡时间，导致该日异常原因不准确。
- 落在**工作日**的法定节假日，如果页面只用 CSS class 标记而没有文字，目前可能被当成普通工作日。
- 「全天无打卡」标记只覆盖**当前月份已过去**的自然工作日；历史月份不标记（避免旧数据不全造成误判）。
- 「忘刷卡」卡片的分母固定显示 `4 次`。
- 仓库内文件名仍是 `4.4.2`，脚本实际版本为 `4.4.7`。

## 开发

单文件项目，没有 `package.json`、没有构建、没有依赖。

```bash
# 语法检查
cp "H3C 考勤工时助手-4.4.2.txt" /tmp/check.js && node --check /tmp/check.js
```

代码按注释分区组织，顺序大致为：配置 → 存储 → 状态 → 图标 → 通用工具 → 考勤规则 → 日历读取 → 打卡解析 → 请假解析 → 数据提取 → 工时计算 → 剩余工作日 → 历史趋势 → 日历着色 → 页面渲染 → 模式视图 → 设置 → 面板创建/事件 → 刷新与防抖 → 日历监听 → 拖动 → 面板位置 → 注入样式 → 启动。

修改后请同步递增脚本头的 `@version`。
